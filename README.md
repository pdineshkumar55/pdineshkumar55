# Hi, I'm Dineshkumar Palanisamy 👋

**Tech Lead @ Ovyo · Senior Roku / OTT Engineer · Building with GenAI**

I've spent 12+ years building streaming apps for Roku, with BrightScript and SceneGraph, for media and OTT clients. Today I lead a small engineering team and work on architecture, delivery, code reviews and Roku certification. I'm also building hands-on depth in Generative AI: RAG, knowledge graphs and agentic automation.

---

### 📺 What I do

- **Roku app development:** BrightScript and SceneGraph, video playback, in-app purchases, and taking apps through Roku certification
- **White-label OTT architecture:** JSON-config-driven Roku apps, where one core codebase is themed and configured per client
- **Technical leadership:** team mentoring, code reviews, effort estimation for RFQs, and technical interviewing
- **AI-assisted engineering:** using Claude Code in day-to-day Roku development
